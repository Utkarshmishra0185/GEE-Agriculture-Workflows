# Repository 3: GEE-Agriculture-Workflows

## Repository Description

Google Earth Engine workflows for agricultural monitoring, crop mapping, vegetation analysis, and satellite-based decision support using Sentinel-2 imagery.

## README Introduction

This repository contains Google Earth Engine scripts developed for agricultural applications using Sentinel-2 satellite imagery. The workflows support crop monitoring, vegetation assessment, district-level analysis, and agricultural decision-making through cloud-based geospatial processing.

## Key Features

* Sentinel-2 preprocessing
* Cloud filtering
* District-level extraction
* False Colour Composite generation
* Crop health monitoring
* Agricultural land assessment
* Export automation

## Technologies Used

* Google Earth Engine
* JavaScript
* Sentinel-2
* Remote Sensing
* GIS
